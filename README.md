# amirtaherin.github.io

Personal academic website of Amir Taherin, built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

Deployed automatically by GitHub Actions (.github/workflows/deploy.yml) to the gh-pages branch on every push to main.

Common updates (all editable on github.com, no local tools needed):
- News: add a file in `_news/`
- Publication: add a BibTeX entry in `_bibliography/papers.bib`
- Bio/education/positions: `_pages/about.md`
- CV page data: `_data/cv.yml` · CV PDF: `assets/pdf/AmirTaherin_CV.pdf`
- Profile links: `_data/socials.yml` · Photo: `assets/img/prof_pic.jpg`

Previous sites: branch `old_2025_page` (Wowchemy, pre-2026) and `jekyll-2026` (minimal Jekyll).
